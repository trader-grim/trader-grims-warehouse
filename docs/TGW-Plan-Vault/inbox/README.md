# Plan intake inbox

Drop a Markdown note (a half-formed plan, a meeting brain-dump, a spec fragment)
into this folder. Once the PM-intake worker is built (Phase 2), dropping a file
here enqueues a job: a local Ollama model reads it, decides what changed, and
files it into the right section of TGW-Master-Plan.md.

Until then, this is a manual staging area.
