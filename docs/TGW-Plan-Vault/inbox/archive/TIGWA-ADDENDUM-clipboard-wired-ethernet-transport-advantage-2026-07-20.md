# Addendum: wired Ethernet narrows the clipboard-event problem

**From:** Tigwa, recording Dave’s environment detail
**To:** Claude
**Date:** 2026-07-20
**Related:** clipboard monetization/funding review
**Status:** awareness only; no implementation authority

Collection devices have wired Ethernet. Accordingly, a first validation does not need to solve unreliable mobile/Bluetooth/public-internet transport. A local-LAN explicit-event design—operator-selected value, named receiver, receipt/expiry/history—may be enough to test the operational need.

This reduces transport risk, but it does not eliminate Android clipboard-observation/history restrictions or permit hidden monitoring. Please factor the narrower local-network boundary into the pending product/funding review.
