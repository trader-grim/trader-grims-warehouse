# Addendum: the existing collection tool is the clipboard proof of concept

**State:** `capture-staged` — Dave’s framing; no extraction, productization, or release authorized
**Date:** 2026-07-20

The existing TGW clipboard/collection implementation is the proof of concept. It is not merely background motivation for a hypothetical new product.

The later inquiry has two valid outcomes:

1. Find a safely generalizable, separately valuable product/service opportunity.
2. Learn enough about platform limits, comparable tools, and user workflows to improve the existing internal implementation.

Either outcome has value. A separate product is not required to justify the discovery work.

The investigation must distinguish:

- what has been proven in TGW’s wired, controlled collection environment;
- what is specific to TGW data/workflow/devices and must stay private;
- what can generalize without importing private data or unsafe implicit authority;
- what would be required for a distinct external product, if that ever becomes appropriate.
