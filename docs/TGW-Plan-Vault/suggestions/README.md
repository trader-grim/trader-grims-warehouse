# Suggestion box

`tgw suggest "your idea"` appends a timestamped line here. These are collected,
not acted on immediately — they get reviewed and integrated at the next planning
session with Opus.

Convention (Phase 2 will automate this):
    - [ ] 2026-05-31T14:22 :: idea text here

Until the CLI exists, just add lines by hand in the same format.
