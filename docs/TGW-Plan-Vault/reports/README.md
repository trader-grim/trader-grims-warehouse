# Reports

**Provisional, 2026-07-16.** Created as a stopgap during a plan-reconciliation
pass. Filing locations/taxonomy are the librarian's (Tigwa/Leotha) authority
going forward, per Dave 2026-07-16 — see `PP-KNOWLEDGE-001`'s "Filing
authority" note in the master plan. Treat this folder and its rules below as
subject to the librarian's own reconciliation, not a Claude-owned convention.

Intent (until superseded): standing/periodic reports that are informational,
not actionable — monitoring snapshots, status-of-status reports, "no action
necessary" writeups. Filed here directly by whoever produces them, never
routed through `inbox/` for processing, because there's nothing to triage.

If a report is relevant to an active PP, the master plan gets **at most a
one-line pointer** to the file here — never the full narrative duplicated into
`TGW-Master-Plan.md`. See the `tgw-plan-maintain` skill (`.claude/skills/`) for
the interim rule set on what belongs in the plan vs. here vs. `pp/`.

Distinct from:
- `inbox/<actor>/` — items awaiting processing/action, deleted or moved once handled
- `tigwa-reviews/` — Tigwa's specific contract-review outputs
- `pp/` — full PP design docs, the plan's own detail layer
