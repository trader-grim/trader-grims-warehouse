## Prompt

I run an automated eBay resale operation listing used/secondhand items across many categories
(games, toys, collectibles, electronics, household goods). I want current, cited information
on eBay's Cassini search algorithm as it stands in 2025–2026.

**Research the following and provide cited answers:**

### Ranking signals — current weights and priorities
- What are the most important signals Cassini uses to rank listings in 2025?
- Have the relative weights of title quality vs. item specifics vs. price vs. seller metrics
  changed in the last 12–18 months?
- Is there any official eBay communication (Seller Center updates, developer blog, seller
  news) about Cassini changes in 2025?

### Used/secondhand listing optimization
- For used items (not new), which signals have the biggest impact on search placement?
- Does condition granularity matter? (e.g., "Used – Excellent" vs. just "Used")
- How much does item specifics completeness affect placement for used goods where many
  specifics are unknown or not applicable?

### eBay Catalog (EPID) association
- What is the SEO benefit of associating a listing with an eBay Catalog EPID?
- Does eBay auto-fill item specifics from EPID, and does that affect Cassini placement?
- For used items, is EPID association still beneficial even if the item is not "new"?

### Title strategy
- What is eBay's current guidance on title construction? (80 chars, brand + model, etc.)
- Are there known penalties for keyword stuffing or ALL-CAPS in titles as of 2025?
- How does Cassini weight brand + MPN in the title vs. those same values in item specifics?

### Description and photo count
- Does description length still matter (200+ words)? Is HTML formatting in descriptions
  indexed or ignored by Cassini?
- What is the current eBay recommendation on photo count, and is there a threshold that
  triggers a penalty vs. a boost?

**Format:** One section per topic, with "Current best practice" summary and "Caveats /
uncertainties". Include dates on all sources.
