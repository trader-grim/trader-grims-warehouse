# Plan Authority Cutover

The synced source-tree vault is not a Plan authority. It retains inbox,
archive, research, and reference material only.

Operational Plan consumers must use the separately materialized standalone
Plan repository and require its exact approved Git commit plus approved
solution hash. The running process reports that bound identity with every
Plan-derived result. A local file path, a vault tab, or an unpinned checkout
is not an approval.

This notice is intentionally the vault's default navigation target so opening
the vault cannot imply that its historical `plan/` files are current
authority. Historical material is preserved; it is not deleted or rewritten.
