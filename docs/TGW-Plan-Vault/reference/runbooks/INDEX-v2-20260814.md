## Rules shared by every successor runbook

1. Verify the actual live source, service `ExecStart`, selected release, Nix closure,
   and user-visible behavior before saying a change is installed.
2. Plan approval covers the declared solved phases. Do not interrupt implementation,
   review, integration, candidate installation, and verification with repeated
   ceremonial approval requests. Ask again only for a genuinely new or broadened
   effect.
3. Source selection, runtime-wheel installation, NixOS activation, database/schema
   mutation, and provider effects are separate transitions with separate evidence.
4. Never infer success from a commit, build, receipt, or active service alone. The
   applicable live acceptance check must pass.
5. Preserve authorities, observations, queue history, provider effects, installer
   receipts, and old immutable generations. Rollback changes selection/runtime; it
   does not erase business or evidence records.
6. Do not print secrets, private keys, OAuth tokens, complete provider payloads, or
   environment-file contents into logs or runbooks.
7. `CLAUDE.md` is not a generic coding contract. Each harness follows its own
   instructions plus the standalone Plan and the exact execution card/task.

## Where to start

- A host or service is down: start with
  [day-two platform operations](full-platform-operations-v2-20260814.md).
- A source or platform change is requested: start with
  [governed coding and release](governed-coding-release-v2-20260814.md).
- A Nix module/unit/host change is requested: use
  [Nix flake maintenance](nix-flake-maintenance-v2-20260814.md).
- An item cannot prepare, upload, stage, or publish: use
  [listing workflow operations](listing-workflow-operations-v2-20260814.md), then
  the detailed PP-WORKFLOW-001 reconciliation runbook it links.
- A replacement machine must be installed from bare metal: use the historical
  `nixos-prod-cutover-runbook.md` only as recovery evidence, reconcile every device,
  input, secret, and current flake identity first, and then apply the current full
  installation runbook.
