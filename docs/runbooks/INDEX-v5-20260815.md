The three repositories are separate:

- application source and development are on tgw-lib;
- Plan authority and governed execution are on tgw-lib;
- the production NixOS flake is on tgw-prod.

tgw-prod contains immutable application releases selected through
`/opt/TGW/current`, but no application source checkout and no Plan checkout.
The Plan Syncthing sender is tgw-lib, not production.
