# perplexity api pricing

Perplexity API pricing is split by product: the **Search API** is billed at \$5.00 per 1,000 requests with no token charges, while the **Sonar API** uses token pricing plus a request fee that depends on search context size. The API docs also say the **Agent API** is priced at direct provider rates with no markup, and the **Embeddings API** has separate per-1M-token pricing.[^1_2]

## Search API

The Search API costs \$5.00 per 1,000 requests and returns raw web search results with advanced filtering. There are no additional token costs for this API.[^1_2]

## Sonar API

For Sonar, pricing is token-based plus a request fee. The docs list these token rates: Sonar at \$1 input / \$1 output per 1M tokens, Sonar Pro at \$3 input / \$15 output, Sonar Reasoning Pro at \$2 input / \$8 output, and Sonar Deep Research at \$2 input / \$8 output plus citation/search/reasoning token charges.[^1_2]

Request fees for Sonar depend on search context size: Sonar is \$5 / \$8 / \$12 per 1,000 requests for low / medium / high context, and Sonar Pro and Sonar Reasoning Pro are \$6 / \$10 / \$14 for the same tiers.[^1_2]

## Agent API

The Agent API uses transparent token-based pricing at direct provider rates, and the docs say pricing varies by model/provider. It also has separate tool fees such as web search at \$0.005 per invocation and fetch URL at \$0.0005 per invocation.[^1_2]

## Embeddings API

The Embeddings API pricing is listed separately: `pplx-embed-v1-0.6b` is \$0.004 per 1M tokens, `pplx-embed-v1-4b` is \$0.03, `pplx-embed-context-v1-0.6b` is \$0.008, and `pplx-embed-context-v1-4b` is \$0.05.[^1_2]
