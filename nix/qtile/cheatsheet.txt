── Window Focus ──────────────────────────────────────────────────
  Super+h/j/k/l        Focus left/down/up/right
  Super+Shift+h/j/k/l  Move window left/down/up/right
  Super+Ctrl+h/j/k/l   Resize window
  Super+Ctrl+n          Normalize sizes

── Layouts ───────────────────────────────────────────────────────
  Super+Tab             Next layout
  Super+Shift+Tab       Prev layout
  Super+f               Toggle fullscreen
  Super+Shift+f         Toggle floating

  Active layouts (in order):
    MonadTall   main pane left 55%, stack right       ← default
    MonadWide   main pane top, stack below
    Columns     3-column equal split
    Max         single window, no borders

  Also available (add to config.py, no rebuild — just Super+Ctrl+r):
    BSP         recursive binary splits; good for terminal-heavy work
    Spiral      like BSP but spiral inward
    Stack       independent stacks side by side
    TreeTab     sidebar tab list + main pane; good for many named windows
    Tile        master-stack with tunable master count
    Matrix      equal grid; dashboard-style
    Plasma      free-form draggable tiling (most mouse-driven)
    Slice       reserve a fixed strip for one window (e.g. status pane)
    Zoomy       focused window expands; others shrink to icons
    VerticalTile  like MonadTall but mirrored
    ScreenSplit   sub-screen partitioning (multi-monitor simulation)

── Windows ───────────────────────────────────────────────────────
  Super+w               Close window
  Super+Ctrl+r          Reload Qtile config (keybinds + layout changes — instant)
  Super+Ctrl+q          Quit Qtile

── Launch ────────────────────────────────────────────────────────
  Super+Enter           Terminal (konsole)
  Super+d               App launcher (dmenu / j4-dmenu-desktop)
  Super+r               Run command (Qtile prompt in bar)
  F12                   Scratchpad terminal toggle

── Workspaces ────────────────────────────────────────────────────
  Super+1   shell  — general terminal / dev
  Super+2   tgw    — MC, dashboard, logs
  Super+3   ebay   — browser (Seller Hub)
  Super+4   agents — Claude Code, AI tools
  Super+5   media  — photo intake, Gwenview
  Super+Shift+1–5   Move window to workspace

── TGW Chord: Super+T ────────────────────────────────────────────
  (bar shows [ TGW ] while in chord mode)
  h     tgw health check
  q     queue depths (psql)
  s     tgw staged items
  t     tgw todo
  v     tgw velocity-report
  c     clipboard SKU → lookup
  1     queue ai_identify for clipboard SKU
  2     queue ebay_draft for clipboard SKU
  o     open ItemData in Dolphin
  F2    jump to tgw workspace
  F4    jump to agents workspace
  Esc   exit TGW mode

── Bar Widgets ───────────────────────────────────────────────────
  GroupBox        workspace names (active = accent colour)
  CurrentLayout   active layout name
  Prompt          Super+r run prompt
  WindowName      focused window title
  Chord           shows [ TGW ] in chord mode
  TGWSKUWidget    clipboard SKU watcher — ⬟ tgwXXX when detected
  TGWQueueWidget  Q:✓ / Q:3p / Q:2p 1✗  (click opens health term)
  TGWHealthWidget W:18/18 active/total workers
  Clock           date + time

── Applications ──────────────────────────────────────────────────
  Terminals:    konsole (default)  xterm (fallback)  F12=scratchpad
  Browsers:     firefox  google-chrome
  Files:        dolphin  gwenview (images)  libreoffice
  System:       blueman (bluetooth)  solaar (logitech)  kcalc
                obsidian (plan vault)  vscodium  krfb (VNC host)
  Remote:       tigervnc (VNC client)  cloudflared  krfb

── Clipboard ─────────────────────────────────────────────────────
  tgw clip list                  history (recent 20, 80-char preview)
  tgw clip last-sku              most recent SKU regardless of current clip
  tgw clip get --id N            full content of entry N
  tgw clip get --id N --copy     full content + copy back to clipboard
  tgw clip search <pattern>      search history
  xclip -o                       read X11 clipboard
  wl-paste                       read Wayland clipboard
  xdotool key ctrl+v             simulate paste keystroke
